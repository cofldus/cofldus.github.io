역할RAG 파이프라인 전체 설계 · FAISS 청크 전략 실험 · LangChain RetrievalQA 체인 구현 · 재현성 확보를 위한 캐싱 레이어 개발
핵심 구현
1강의 문서 → FAISS 벡터 인덱싱 → 관련 청크 검색 → LLM 퀴즈·해설 자동 생성 파이프라인 구축
2LangChain RetrievalQA 체인으로 강의 맥락 기반 객관식·서술형 혼합 문제 생성, 난이도 조절 프롬프트 설계
3학습 가이드 자동 요약: 핵심 개념 추출 → 마인드맵 구조 텍스트로 재구성, 수강생 복습 효율 개선
기술 선택 근거
RAG vs Fine-tuning
강의 자료는 수업마다 완전히 달라집니다. Fine-tuning은 새 강의마다 재학습이 필요해 운영 비용이 기하급수적으로 늘어납니다. RAG는 FAISS 인덱스를 교체하는 것만으로 새 강의에 즉시 적응할 수 있어 업데이트 비용 없이 도메인을 바꿀 수 있다는 점이 결정적이었습니다.
FAISS 단독 의미 검색
강의 자료는 전문 용어보다 개념 흐름이 중요합니다. BM25 키워드 검색은 표면 단어가 없는 관련 문단을 누락시키는 반면, FAISS 의미 검색은 맥락이 연결된 단락을 함께 검색해 퀴즈 문항의 완성도가 높았습니다.
