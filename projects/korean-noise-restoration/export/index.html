프로젝트 개요
목표자음·모음 치환, 받침 탈락 등 의도적 난독화로 필터를 우회하는 악성 리뷰를 원형 한글로 복원, 콘텐츠 모더레이션 신뢰도 향상
역할노이즈 패턴 분석 · Seq2Seq 복원 모델 설계 및 학습 · 음소 토크나이저 커스터마이징 · 평가 파이프라인 구축
핵심 구현
1KoELECTRA Noise Classifier로 입력 유형 판별 후 야민정음·음운오류 전용 KoBART 모델로 분기 처리
2핵심 선행 과제: BPE 토크나이저가 야민정음 자모를 분해 실패 → JAMO(초·중·종성) 전처리로 토큰 손상 원천 차단
3BERTScore 0.9812 · CER 0.0426 달성, 분기 설계 도입 전 베이스라인 대비 +5.6%p 개선
기술 선택 근거
분기 설계 vs 단일 seq2seq 모델
야민정음은 자모의 시각적 유사성('ㅎ → 흐'), 음운 오류는 발음의 음성적 유사성('됩니다 → 됩니당')이 변형 기제입니다. 두 방향은 복원에 필요한 지식 공간이 달라, 단일 모델이 같은 파라미터로 둘을 동시에 처리하면 손실 함수가 서로 상충해 불안정한 출력이 나왔습니다. 분류기로 유형을 먼저 판별하고 전담 모델로 라우팅하자 각 모델이 한 방향에 집중할 수 있었습니다.
JAMO 전처리 vs 기본 BPE 토크나이저
'뫄'처럼 야민정음으로 변형된 자모는 한국어 BPE 어휘에 없거나 OOV로 처리돼 [UNK]가 됩니다. 토크나이저 단계에서 정보가 유실되면 그 이후 어떤 모델을 써도 복원이 불가능합니다. 자음·모음을 초·중·종성으로 분리하면 변형된 자모도 기존 어휘 조합으로 표현되어 토큰 손상 자체를 막을 수 있었습니다.
