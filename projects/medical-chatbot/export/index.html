코퍼스
목표Naive RAG의 낮은 Recall 한계를 하이브리드 검색 + 리랭커로 극복, 전문 의학 5.5만 건 코퍼스 기반 고정밀 자문봇 구축
역할BM25+FAISS 하이브리드 파이프라인 설계 · bge-reranker 통합 · 평가 지표(Accuracy, BERTScore) 실험 및 분석
핵심 구현
1하이브리드 검색 설계: BM25(k=20, 용어 매칭) + FAISS(k=20, 의미 검색) 병렬 수행으로 Recall 상한 제거
2BAAI/bge-reranker-v2-m3 재순위: 40개 후보→Top-5 압축으로 LLM 컨텍스트 노이즈 최소화
3ReRanker 전후 비교: 객관식 정확도 +0.04, 서술형 BERTScore +0.16 향상, 단일 벡터 RAG 대비 명확한 개선
기술 선택 근거
BM25 + FAISS 하이브리드 vs 단일 벡터 검색
'폐색전증의 D-dimer 기준치'처럼 전문 의학 용어는 의미 임베딩 공간에서 일반 단어와 거리가 좁아 벡터 검색만으로는 Recall 상한이 낮습니다. BM25는 정확한 용어 매칭을, FAISS는 의미적 유사성을 각자 담당하도록 역할을 분리하고 결과를 병렬로 합산했습니다. 어느 한쪽만 쓸 때보다 Recall 커버리지가 눈에 띄게 올라갔습니다.
bge-reranker vs 단순 Top-K 절삭
BM25+FAISS로 40개 후보를 뽑은 뒤 전부 LLM 컨텍스트에 넣으면 관련 없는 문서가 섞여 답변이 흔들렸습니다. Reranker는 질문과 각 문서를 교차 인코딩해 정합성을 재평가하기 때문에, 단순 점수 기반 Top-K 절삭보다 노이즈 문서를 정확히 걸러냅니다. Top-5로 압축했을 때 BERTScore +0.16이 나왔고, Top-10에서는 개선폭이 절반 이하였습니다.
