JAMO 전처리 vs 기본 BPE 토크나이저
'뫄'처럼 야민정음으로 변형된 자모는 한국어 BPE 어휘에 없거나 OOV로 처리돼 [UNK]가 됩니다. 토크나이저 단계에서 정보가 유실되면 그 이후 어떤 모델을 써도 복원이 불가능합니다. 자음·모음을 초·중·종성으로 분리하면 변형된 자모도 기존 어휘 조합으로 표현되어 토큰 손상 자체를 막을 수 있었습니다.

핵심 구현
1모델 압축: LoRA + 4-bit NF4 양자화 + 멀티링구얼 토큰 Pruning(~10%) 조합으로 14GB→3.0GB(76%), CPU 추론 0.3s
2지식 분리: FAISS(IVF) + SQLite LRU 캐시 하이브리드로 630개 콩글리쉬 패턴 DB를 0.02초 내 검색하는 개인화 메모리

기술 선택 근거
LoRA + 4-bit NF4 + 토큰 Pruning 조합
세 기법은 각각 다른 병목을 공략합니다. LoRA는 파라미터 수를 줄이고, NF4 양자화는 가중치 비트폭을 줄이며, 멀티링구얼 토큰 Pruning은 한국어에 불필요한 어휘를 제거해 메모리를 추가로 확보합니다. 어느 하나만 적용하면 목표인 3.0GB에 도달하지 못했고, 세 가지를 조합했을 때 76% 압축과 CPU 0.3s 추론을 동시에 달성했습니다.
전용 FAISS 벡터 DB로 콩글리쉬 지식 분리
630개 콩글리쉬 패턴을 파인튜닝으로 LLM에 주입하면 용례가 희소해 모델이 일관되게 기억하지 못합니다. RAG로 매번 검색하면 추론 지연이 늘어납니다. 전용 DB에 패턴을 저장하고 LLM은 문법·문맥 판단에만 집중하도록 역할을 분리하자 속도와 정확도 모두 올라갔습니다.

KMeans 군집화로 비교 컨텍스트 제공
단일 기업의 지표만 보여주면 LLM이 '높다/낮다'를 판단할 기준이 없어 애매한 해설이 나옵니다. 동종 업종·규모 유사 기업 군집의 평균 패턴을 컨텍스트에 함께 주입하면 GPT-4가 상대적 위치를 명확히 서술할 수 있었습니다. 군집화는 비교 기준을 자동으로 생성해주는 역할을 했습니다.

의료진 평가
목표페어 데이터 없이 CT↔MRI 교차 변환 모델을 연구, 부족한 의료 모달리티를 AI로 보완할 수 있는 가능성 탐구 및 논문 기여
역할CycleGAN 모델 구현 및 학습 · 데이터 전처리 파이프라인 구축 · FID/SSIM 평가 · 연구원 단기 근무로 논문 작성 참여
핵심 구현
1Loss 조합 실험: ResNet-9 + VGG Perceptual Loss + Identity Loss로 저주파 구조(뼈·장기 경계) 보존, Spectral Norm으로 학습 안정성 확보
2GAN 학습 불균형 해소: G·D 학습률 분리(2e-4/1e-4) + 업데이트 비율 G:D=2:1 설계로 모드 콜랩스 없이 수렴
3정량 평가: SSIM 0.82→0.88(+6.2%p), 해부학적 구조 유실률 30% 감소 · 의료진 맹검 평가 80% '진단 보조 가치 있음'
기술 선택 근거
CycleGAN (Unpaired) vs Pix2Pix (Paired)
실제 임상에서 동일 환자의 CT와 MRI를 같은 시점에 동시 촬영하는 경우는 거의 없습니다. Paired 데이터셋 구축은 비용과 윤리적 제약이 커서 현실적이지 않았습니다. CycleGAN의 Cycle-Consistency Loss는 페어 없이 두 도메인 간 변환을 학습할 수 있어 임상 제약을 우회하는 유일한 방법이었습니다.
VGG Perceptual Loss 추가
Pixel-level L1 Loss만 사용하면 이미지가 전반적으로 블러해지면서 뼈 경계나 장기 윤곽 같은 고주파 구조가 뭉개졌습니다. VGG 중간 레이어의 feature map을 비교하는 Perceptual Loss는 픽셀 단위가 아닌 의미적 구조를 보존합니다. 의료 이미지에서 해부학적 경계 보존은 진단 가치와 직결되기 때문에 이 Loss를 추가하는 것이 핵심이었습니다.

목표강의 영상·자료 업로드만으로 퀴즈·학습 가이드를 자동 생성, 강사의 반복 출제 시간을 RAG 파이프라인으로 완전 자동화
역할RAG 파이프라인 전체 설계 · FAISS 청크 전략 실험 · LangChain RetrievalQA 체인 구현 · 재현성 확보를 위한 캐싱 레이어 개발
핵심 구현
1강의 문서 → FAISS 벡터 인덱싱 → 관련 청크 검색 → LLM 퀴즈·해설 자동 생성 파이프라인 구축
2LangChain RetrievalQA 체인으로 강의 맥락 기반 객관식·서술형 혼합 문제 생성, 난이도 조절 프롬프트 설계
3학습 가이드 자동 요약: 핵심 개념 추출 → 마인드맵 구조 텍스트로 재구성, 수강생 복습 효율 개선
기술 선택 근거
RAG vs Fine-tuning
강의 자료는 수업마다 완전히 달라집니다. Fine-tuning은 새 강의마다 재학습이 필요해 운영 비용이 기하급수적으로 늘어납니다. RAG는 FAISS 인덱스를 교체하는 것만으로 새 강의에 즉시 적응할 수 있어 업데이트 비용 없이 도메인을 바꿀 수 있다는 점이 결정적이었습니다.
FAISS 단독 의미 검색
강의 자료는 전문 용어보다 개념 흐름이 중요합니다. BM25 키워드 검색은 표면 단어가 없는 관련 문단을 누락시키는 반면, FAISS 의미 검색은 맥락이 연결된 단락을 함께 검색해 퀴즈 문항의 완성도가 높았습니다.
